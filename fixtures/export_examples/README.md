# Reviewed Export Fixtures

These deterministic test artifacts are owned by P8-010 and generated by
`services/runtime/scripts/build_export_examples.py` through production adapters.
They are not live runtime output, project backups, or a second serializer.

- `aurora-whole.golden.*`: complete independent Aurora Export example.
- `aurora-main.golden.*`: Main Story plus its invoked-flow dependency closure.
- `citadel-whole.golden.*`: empty but valid JSON/YAML, without synthetic content.
- Source: `fixtures/projects/project-aurora-export.v1.json`, independently owned
  and derived from the unchanged Canon diagnostic fixture.

Run from the repository root:

```bash
uv run python -m services.runtime.scripts.build_export_examples --check
uv run pytest services/runtime/tests/test_export_examples.py -q
```

Omit `--check` only when intentionally updating reviewed fixtures. Tests compare
exact bytes and semantic JSON/YAML parity. Fixture generation disables compiler
validation to avoid machine-dependent output; official compiler acceptance is
covered separately. Never copy databases, `.narrative` folders, runtime `exports/`,
credentials, or local project paths here.
