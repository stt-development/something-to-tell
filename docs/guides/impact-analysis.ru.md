# Оценка влияния изменения

Анализ влияния отвечает: *что может затронуть изменение или удаление этого
элемента?* Запускайте его перед рискованной правкой. Просмотр не применяет изменение.

## Анализ выделения

1. Выделите элементы графа и запустите анализ текущего выделения либо откройте
   анализ влияния через меню анализа в верхней панели.
2. Выберите намерение изменения или удаления, направление и глубину просмотра.
3. Запустите анализ и прочитайте группы результатов.
4. Разверните путь зависимости, чтобы понять причину появления элемента.
5. Откройте источник результата, если нужно посмотреть авторское содержимое.

Смена выделения обновляет предлагаемый охват, а не смысл уже полученного
результата. Для нового выделения запустите анализ ещё раз.

## Как читать результат

| Зависимость | Значение |
|-------------|----------|
| Обязательная | Зависимый элемент не сохранит нынешний смысл без этого ресурса |
| Условная | Может измениться определённая ветка или состояние |
| Контекстная | Есть связь по смыслу; поломка исполняемого пути не доказана |

Например, удаление ответа с передачей ключа может повлиять на условие у ворот
и вызванный квест. Связь персонажей рядом с этим действием — контекст,
а не доказательство неверности самой связи.

## Проверка предложенного изменения

Подтверждение удаления и предложения исправлений могут содержать действие
анализа влияния. Изучите просмотр и вернитесь к исходному решению. Закрытие
ничего не удаляет, не принимает и не сохраняет. Если проект изменился, обновите
анализ: старые данные больше не подходят для принятия решения. После реальной
правки проверьте результат каноном, а не заменяйте его анализом влияния.
