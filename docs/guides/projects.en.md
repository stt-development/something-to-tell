# Projects and saving

A project keeps the elements, story flows and settings for one work. The start
screen does not open a sample automatically: create a project or open your own.

## Create or open

1. Choose **Create**, enter a name and choose a parent folder. A separate project
   folder is created there. Add a description to recognise it later.
2. To return to existing work, choose **Open** and select its containing directory.
3. Select the project card in the available-project list. If it is missing,
   check the selected directory and refresh the list before creating a duplicate.

In an open project, use the sidebar's **Open** and **Create** actions to switch.
When prompted, decide what to do with unsaved changes first.

## Save, autosave and a separate copy

- **Save** records current work in the current project. The save button indicates
  changes; the status appears briefly at the bottom right after saving.
- **Autosave** is configured in **Project settings**. Its default interval is
  five minutes. Do not close the app while an important save is still running.
- Open the arrow beside Save and choose **Save As** to make a separate project
  copy. Check its destination and storage choice before confirming.

Export is different: it produces files for another tool, not a complete editable
project copy. A save failure is not proof that your work was saved; read its
message and keep the project open until you have chosen a safe recovery action.

## Settings and language

Open the gear button for **Project settings**. Change the name, description,
autosave, interface language or content language and save the settings.
Interface language controls buttons and guides. Content language controls the
language requested from AI assistance; it does not translate your existing text.

## Close safely

Use **Close project**. If there are unsaved changes, Save keeps them, Discard
returns to the last saved version and Cancel stays in the project. Undo/Redo
helps with recent authored commands but is not a substitute for a separate copy.
