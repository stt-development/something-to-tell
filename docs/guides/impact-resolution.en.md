# Explore solutions

Use solution exploration when an Impact finding or Canon issue needs an authoring
decision, not a single obvious repair. A configured assistant can explain the
problem and propose alternatives; it cannot decide your story for you.

## Request alternatives

1. Run Impact Analysis, or choose **Explore solutions** on a supported Canon issue.
2. Open **Resolution review**, marked with a bot icon.
3. Select the findings you want explained.
4. Read what will be sent, grant consent and choose **Explain findings**.
5. Review the summary, why it matters, assumptions and limitations.

If assistance is unavailable, check the Impact Resolution provider/model in
Project settings. Local findings remain useful without generated solutions.

## Compare before accepting

Select an alternative and compare **Before**, **After** and **Changes**. Inspect
affected Graph, Flow, Story, Dialogue, Quest or state elements. A text explanation
is not proof that the proposed route executes correctly.

- A valid alternative with actual changes can be approved, rejected or edited.
- Explanation-only guidance has no changes to apply; decision/visual controls
  can therefore be unavailable.
- An invalid alternative shows its problems and cannot be applied.

## Decide and verify

Approve only after reviewing every change. Edit requests a new validation;
Reject leaves the story unchanged. Previously rejected alternatives are included
again only when you request that option. Undo can reverse an approval.
Rerun Impact or Canon afterward and save separately. If you edit, save or switch
the project during review, request fresh alternatives rather than using stale ones.
