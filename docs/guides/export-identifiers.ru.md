# Идентификаторы экспорта

Идентификаторы экспорта задают стабильные имена элементов для внешних инструментов.
Они отличаются от обычных авторских тегов и не меняют порядок истории.

## Имя отдельного элемента

1. В редакторе элемента разверните **ID экспорта**.
2. Просмотрите назначенные имена. Новый сохранённый элемент получает начальный
   идентификатор автоматически; повторное открытие использует его же.
3. Карандаш позволяет изменить имя на месте, добавление идентификатора — найти
   и назначить существующий.
4. Чтобы создать ещё один, сформируйте новый идентификатор, проверьте имя и сохраните.

Вложенные элементы диалога и квеста получают имена при сохранении этих правок.
Один идентификатор может иметь несколько владельцев. Снятие привязки не удаляет
сам элемент истории.

## Реестр проекта

Откройте **Идентификаторы экспорта** кнопкой с тегом возле настроек проекта.
Используйте поиск и фильтры, выберите определение и просмотрите привязки. Задавайте
уникальные имена с точками, например `Character.GateGuard`. Для нескольких
элементов графа используйте привязку ID экспорта к выделению.

## Имена для Ink и Yarn Spinner

Выберите формат в блоке идентификаторов формата, проверьте поле
**Идентификатор формата** и сохраните его. Новые определения получают начальные
имена; старым может потребоваться добавить их вручную. Смена общего ключа не
переименовывает эти имена автоматически. Сформируйте просмотр и проверьте целостность.

Перед экспортом исправьте отсутствующее, неверное или повторяющееся имя формата.
Архивация прекращает использование определения, но не удаляет его. Восстанавливайте
и снимайте привязки осознанно. Правки можно отменить; результат сохраните.
Просмотр и проверка целостности не сохраняют проект и не отправляют данные ИИ.
