# Working on the graph

Use Graph to arrange your story's elements. Their position is a visual aid, not
the order in which the story runs. Story transitions define that order.

## Move around and select

1. Use **Pan canvas**, the hand tool, to move the view without selecting cards.
2. Return to **Select** to select elements. Shift-select or drag a selection area
   to work with several elements, then drag the group together.
3. Zoom with the canvas controls or your usual wheel/trackpad gesture. Fit View
   brings the complete current workspace into view; the MiniMap helps navigate.
4. Click an element's name in the project tree to centre the view on it.

An overview can show compact cards. Zoom in or select a card to access more detail.
This does not delete its text. Move overlapping cards apart when arranging work.

## Create and connect

1. Choose an element type in the left tool rail, then click empty canvas space.
   The right-click menu also offers element types.
2. Double-click a card to edit its name, text and available fields.
3. Drag from a connection point to another card and release. The connection joins
   the closest suitable point. Double-click a relationship to edit its label.
4. Use a node's **Continue from** action for story order. An ordinary relationship
   such as *knows* describes the world; it does not make an action execute next.

Select unwanted elements and use Delete or Backspace. Check what is selected
before deleting; use Undo for an accidental authored change.

## Scenes, Locations and linked appearances

Draw a Scene or Location frame and place elements inside to group them. A Location
cannot contain a Scene. Move a container to move its contents; resize it as needed.
Double-click opens its usual editor. Use its dedicated focus button for a larger
workspace, then return to the whole graph.

A linked appearance shows an existing element in another place. Its chain marker
distinguishes it from a separate character or object. Arrange appearances
independently; editing shared story content affects the same underlying element.
