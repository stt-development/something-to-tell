# Writing style

Style profiles describe how prose should sound. They do not set story order or
replace checks for factual consistency. Use them for text fields, not structural repairs.

## Choose the effective style

1. Open **Project settings → Style**.
2. Create a profile from a preset or write your own guidance and examples.
3. Save the profile and choose it as **Project default** when appropriate.
4. To override one Scene, open its editor and choose **Scene style**.

A Scene style takes precedence over the project default, including text nested
inside its Locations. For a shared element in several Scenes, choose the intended
Scene context in the request. Preset language follows content language.

## Request and review

1. Save the text field you want rewritten.
2. Choose the style recommendation button beside the text. It is available on
   node text and supported Dialogue and Quest text fields.
3. Check the source text, effective style and Scene context. Add a specific
   instruction, such as *keep the hesitation but shorten the answer*.
4. Review the content disclosure, consent and request a recommendation.
5. Compare Before, After and Changes, including explanation and factual warnings.

Approve only if names, facts and intent remain right. Reject changes nothing;
add details and request again when needed. A blocked result cannot be approved.

## After a change

Read the revised passage in context, use Undo if needed and run Canon check
when factual risks were reported. Save the project separately. If the source,
style or project changed during the request, open the current text and request
again; an older recommendation is no longer safe to apply.
