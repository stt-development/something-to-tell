# Choose an element type

Choose a type for its meaning, not just its colour. Open a card by double-clicking
to edit its title, text, tags and the fields available for that type.

## People, places and story facts

| Type | Use it for |
|------|------------|
| Character | A person who speaks or acts |
| Faction | A group and its selected Character members |
| Item | An object that can be held or transferred |
| Lore | A fact about the story world |
| Location | A place that can contain other elements |
| Scene | A dramatic unit containing related elements |
| Event | An action or occurrence |
| Dialogue | A conversation with lines, choices and outcomes |
| Quest | An objective with stages, branches and outcomes |
| Condition | A requirement to check before a route or outcome |
| Consequence | A result of an action or decision |

## Build meaningful groups

Create Characters before choosing Dialogue speakers or Faction members. In a
Faction editor, add or remove members rather than using a text tag as membership.
Scene and Location frames show belonging by containment; a Location cannot hold
a Scene. Use a linked appearance when the same element is needed in two places.

## Requirements are not results

A Condition asks *is the gate key available?* A Consequence describes *the gate
is open*. Neither card alone changes what happens during Playback: author a
route condition or state effect at the appropriate story position as well.
Use ordinary relationships for facts such as *knows* or *belongs to* and story
transitions for what happens next. Read connection tooltips before choosing one.

If a container has children, its type cannot be changed like an ordinary card.
Keep its contents organised and edit its text through the usual double-click.
