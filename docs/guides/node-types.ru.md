# Выбор типа элемента

Выбирайте тип по смыслу, а не только по цвету. Двойной клик открывает название,
текст, теги и дополнительные поля, доступные для этого типа.

## Персонажи, места и факты

| Тип | Для чего нужен |
|-----|----------------|
| Персонаж | Тот, кто говорит или действует |
| Фракция | Группа с выбранными персонажами-участниками |
| Предмет | Объект, которым можно владеть и который можно передать |
| Лор | Факт об устройстве мира |
| Локация | Место, в которое можно поместить другие элементы |
| Сцена | Эпизод, объединяющий связанные элементы |
| Событие | Действие или происшествие |
| Диалог | Разговор с репликами, выборами и результатами |
| Квест | Цель с этапами, ветками и результатами |
| Условие | Требование перед переходом или результатом |
| Последствие | Результат действия или решения |

## Смысловые группы

Сначала создайте персонажей, затем выбирайте их в диалоге или составе фракции.
Добавляйте участников в редакторе фракции: текстовый тег не заменяет членство.
Вложенность внутри сцены и локации показывает принадлежность. Локация не может
содержать сцену. Для одного элемента в разных местах используйте связанный экземпляр.

## Требование отличается от результата

Условие отвечает на вопрос *есть ли ключ от ворот?*, а последствие описывает
*ворота открыты*. Сама карточка не меняет состояние при прохождении: дополнительно
задайте условие перехода или эффект в нужном месте истории.
Обычные связи описывают факты вроде *знает* или *принадлежит*, переходы истории —
порядок действий. Перед выбором соединения прочитайте его подсказку.

Тип контейнера с вложенными элементами нельзя менять как тип обычной карточки.
Редактируйте его описание привычным двойным кликом.
