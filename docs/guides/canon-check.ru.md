# Проверка целостности истории

Проверка канона ищет противоречия и неполные структуры истории. Запускайте её
после правок или перед экспортом. Анализ влияния отвечает на другой вопрос:
что может затронуть предполагаемое изменение.

## Запуск и просмотр

1. В верхней панели откройте **Анализ → Проверка канона**.
2. Запустите проверку. Локальные проверки не требуют провайдера ИИ.
3. Прочитайте пояснение, проблемный элемент и рекомендуемое действие.
4. Один клик выбирает замечание для просмотра; двойной клик или открытие источника
   переводит к элементу. В диалоге проблема видна также возле нужной ветки.

Недостижимому результату обычно нужен корректный маршрут, а не другая формулировка.
Отсутствующей ссылке нужен действительно существующий целевой элемент.

## Устранение причины

- Исправьте источник вручную, если знаете задуманный результат.
- Запросите предложение, если для проблемы доступно безопасное исправление.
- Разбор решений помогает с неоднозначным выбором при настроенном помощнике.
  Перед выбором прочитайте его допущения.

Проверьте изменение, при необходимости оцените влияние, затем примите или
отклоните. Открытие предложения ничего не применяет. Иногда доступен только
переход к источнику: приложение не может безопасно угадать каждое авторское решение.

## Статус не заменяет исправление

Подтверждение ознакомления означает просмотр, а не устранение проблемы.
Игнорирование фиксирует исключение; найти его снова можно фильтром всех или
игнорируемых замечаний. Повторное открытие возвращает замечание к проверке.
Исправив причину, запустите канон снова для подтверждения результата. Сохраните
проект отдельно. Принятую правку можно отменить; устаревший результат запросите заново.
