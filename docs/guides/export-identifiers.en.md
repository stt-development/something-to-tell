# Export Identifiers

Export Identifiers give story elements stable names for use outside the app.
They are separate from ordinary author tags and do not change story order.

## Inspect an element's name

1. Open an element editor and expand **Export ID**.
2. Review assigned identifiers. New saved elements receive an initial identifier
   automatically; reopening the editor should reuse it.
3. Use the pencil to edit an identifier in place, or **Add identifier** to search
   and assign an existing one.
4. To create another, generate a new identifier, review its name and save.

Nested Dialogue and Quest elements receive their identifiers when those edits
are saved. A shared identifier can have several owners; removing a binding is
not the same as deleting the story element.

## Manage the project registry

Open the tag icon, **Export Identifiers**, beside Project settings in the header.
Search/filter definitions, select one to edit and inspect its bindings. Give keys
unique dotted names, such as `Character.GateGuard`. Select multiple Graph elements
and use **Bind Export ID to selection** for a reviewed bulk assignment.

## Names for Ink and Yarn Spinner

Choose a format under **Target identifiers**, review **Target Identifier** and
save it. Newly generated definitions get initial format names; older entries may
need one added. Renaming a display key does not automatically rename these names.
Generate an export mapping preview and run **Check integrity** after changes.

If a format name is missing, invalid or duplicated, correct the definition before
exporting. Archive stops use without removing the definition; restore or remove
bindings deliberately. Undo can reverse edits; Save keeps the reviewed result.
Preview and integrity checks do not save the project or send data to AI.
