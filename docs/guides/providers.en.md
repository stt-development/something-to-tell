# Set up AI assistance

AI assistance is optional. Local Canon and Impact checks and manual story editing
work without a provider. Remote requests may cost money under your provider plan.

## Connect a provider

1. Open **Project settings** and the default agent provider settings, or the
   provider settings for the assistant you want to use.
2. Choose **Add provider profile** and select OpenAI, Google Gemini or Anthropic.
3. Enter a recognisable profile name and your own API key, then connect/verify it.
4. Choose an available compatible model from the loaded list.
5. Enable the intended assistant mode and save project settings.

You can use a project-default provider or override it for one assistant. Each
assistant chooses its own model. Choosing a provider does not enable every agent
or guarantee every model supports that agent's request.

## Review every request

Read the content disclosure and applicable saved guidance before consenting.
Only request assistance with material you are permitted to send to that provider.
Your interface language controls the UI; project content language controls the
requested response language. Neither setting translates already authored text.

Never put a key into story text, tags, assistant memory or screenshots. Provider
keys stay on this device. On another machine, select or add a provider profile
again; a portable project copy is not a portable provider credential.

## Failed requests

If connection or model selection fails, verify the key, provider access and model
in settings. A rejected/unsupported model may need a different selection.
Failure does not approve a proposal or remove local issues. Review and accept
every proposed change explicitly, then save when satisfied.
