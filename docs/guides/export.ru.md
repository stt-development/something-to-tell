# Экспорт истории

Экспорт создаёт файлы для другого инструмента. Сохранение записывает текущий
проект, «Сохранить как» создаёт редактируемую копию. Экспорт не заменяет копию проекта.

## Выбор формата

| Формат | Назначение |
|--------|------------|
| JSON / YAML | Структурированные данные истории для отдельного рабочего процесса |
| Ink | Исходный текст для проекта на Ink |
| Yarn Spinner | Исходный текст для проекта на Yarn Spinner |

Исполняемые форматы поддерживают определённый набор возможностей истории.
Читайте диагностику просмотра: не любой проект экспортируется без изменений.

## Просмотр и запись

1. Откройте экспорт возле сохранения в верхней панели.
2. Выберите формат и весь проект либо отдельные потоки. Найдите нужные потоки
   поиском; вызываемые потоки и необходимые зависимости включаются автоматически.
3. Для JSON/YAML выберите формат идентификаторов. Ink/Yarn используют свой вариант.
4. Обновите просмотр. Проверьте состав, создаваемый текст, предупреждения и ошибки.
5. Исправьте блокирующие ошибки в исходных элементах и обновите просмотр. Проблемы
   экспортных имён исправляются в идентификаторах экспорта.
6. Оставьте предложенную папку или выберите другую.
7. Запустите экспорт. Разрешайте замену существующего файла только осознанно.
   Прочитайте результат завершения перед открытием папки.

## Проверка вне приложения

Экспорт использует текущую работу, включая несохранённые правки, но не сохраняет
проект. Сокращённое превью не сокращает итоговый файл. После правки проекта,
истечения просмотра или успешной записи обновите просмотр перед новым экспортом.
Если место или охват неверны, отмените до начала записи. Для Ink/Yarn может
потребоваться поддержка в принимающем проекте: запись не устанавливает игру
или внешний редактор. Пройдите ветки и проверьте результат в целевом инструменте
перед распространением.
