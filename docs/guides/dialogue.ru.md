# Ветвящиеся диалоги

Диалог объединяет участников, реплики, выборы и результаты. Сначала создайте
персонажей на графе, затем создайте диалог и откройте его двойным кликом.

## Напишите разговор

1. Найдите нужных персонажей поиском участников и добавьте их в разговор.
2. Добавьте реплику, выберите говорящего и заполните текст.
3. Добавьте следующую реплику или выбор. Выбор содержит вопрос и варианты ответа.
4. Напишите ответы и укажите для каждого следующий элемент разговора или
   завершение. Свяжите начальную реплику с выбором через поле следующего элемента.
5. Назначьте начало диалога. Перестановка карточек для удобства чтения не заменяет
   явно выбранные переходы между ними.
6. Нажмите **Сохранить диалог**. Исправьте сообщения под проблемными элементами,
   прежде чем ожидать корректного прохождения разговора.

## Свяжите результат с историей

Для ответа *Пожалуйста, открой ворота* добавьте результат с существующим событием
или создайте событие прямо в редакторе результата. Соединение появится на графе.
Действие добавления в поток задаёт порядок в текущей истории; для длинной ветки
можно выбрать существующий или новый дополнительный поток. Только смысловая
связь не запускает следующий шаг истории автоматически.

## Проверьте и исправьте

Запустите поток с диалогом, пройдите реплики и выберите ответы. Если ответ
недоступен, проверьте его условие и текущее состояние, а не удаляйте условие
ради доступности. После правки сохраните диалог и начните прохождение заново.

Перед удалением участника переназначьте использующие его реплики. Закрытие
редактора не заменяет **Сохранить диалог**. Рекомендации по стилю доступны возле
текста, а замечания проверки — рядом с проблемным элементом.
